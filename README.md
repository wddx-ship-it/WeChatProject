# 学习计时器 (study-timer-vue)

基于 Vue.js + uni-app 开发的微信小程序学习计时器应用，支持多端运行（微信小程序、H5）。

## 功能特性

✅ **学习计时** - 实时显示学习时长（HH:MM:SS格式）  
✅ **学习类型** - 支持多种学习类型分类记录  
✅ **时间记录** - 自动记录开始/结束时间和学习时长  
✅ **统计分析** - 每周/每月学习统计回顾  
✅ **数据导出** - 支持将学习记录导出为 JSON 文件  
✅ **数据导入** - 支持从 JSON 文件导入学习记录  
✅ **本地存储** - 纯前端部署，所有数据存储在本地  
✅ **历史记录** - 查看和管理过往学习记录  

## 技术栈

- **框架**: Vue 3 + Vite + uni-app
- **状态管理**: Pinia
- **目标平台**: 微信小程序、H5

## 快速开始

### 1. 安装依赖

```bash
npm install
```

### 2. 开发运行

**H5 开发模式:**
```bash
npm run dev:h5
```
访问 http://localhost:5173 即可预览

**微信小程序开发模式:**
```bash
npm run dev:mp-weixin
```
编译完成后，使用微信开发者工具打开 `dist/dev/mp-weixin` 目录

### 3. 生产构建

**H5 生产构建:**
```bash
npm run build:h5
```
构建产物在 `dist/build/h5` 目录

**微信小程序生产构建:**
```bash
npm run build:mp-weixin
```
构建产物在 `dist/build/mp-weixin` 目录

## 数据存储

- 所有学习记录存储在本地 Storage 中
- 数据键名: `studyRecords`
- 数据格式: JSON 数组

### 数据格式示例

```json
[
  {
    "id": 1234567890,
    "type": "数学",
    "startTime": 1234567890000,
    "endTime": 1234567950000,
    "duration": 60
  }
]
```

## 核心功能说明

### 计时器实现
- 使用 `setInterval` 每秒更新一次显示
- 计时器 ID 存储在组件实例属性上，避免内存泄漏
- 在页面卸载时自动清除计时器

### 统计分析
- **周统计**: 最近 7 天的学习数据
- **月统计**: 最近 30 天的学习数据
- **总体统计**: 所有学习记录的汇总
- **类型分布**: 各学习类型的时长占比

### 数据导入导出
- **H5 端**: 完整的导入导出功能
- **微信小程序**: 由于小程序限制，建议在 H5 端进行数据导入导出操作

## 注意事项

⚠️ **TabBar 图标**: 当前使用的是临时 SVG 图标，建议替换为正式的 PNG 图标以获得更好的显示效果。

⚠️ **基础库版本**: 建议在微信开发者工具中将"调试基础库"设置为稳定版本（如 3.4.0 或 3.6.0），避免使用灰度中的高版本导致编译问题。

⚠️ **混合项目**: 如果需要在微信开发者工具中直接运行，请确保 `project.config.json` 中已正确配置忽略非小程序文件。

## 开发规范

- 使用 Vue 3 Composition API
- 遵循 uni-app 开发规范
- 使用 Pinia 进行状态管理
- 计时器更新间隔设置为 1000ms 以优化性能
- 所有 API 调用使用 `uni.` 前缀（而非 `wx.`）以确保跨平台兼容

## 常见问题

### Q: 切换 Tab 后计时器停止？
A: 这是正常行为。可以在页面的 `onShow` 生命周期中恢复计时器状态。

### Q: 数据导入导出不工作？
A: 请在 H5 端进行数据导入导出操作，微信小程序对此功能有限制。

### Q: 编译超时或报错？
A: 检查微信开发者工具的基础库版本，建议使用稳定版本（3.4.0 或 3.6.0）。
